# Consulta Metereológica
## Sobre o projeto
Este projeto consiste em uma aplicação web que permite consultar informações meteorológicas de diferentes cidades.
O objetivo é facilitar o acesso às condições climáticas atuais e à previsão do tempo, apresentando as informações de forma simples e organizada.

## Funcionalidades
- Pesquisar cidades pelo nome.
- Visualizar as opções de cidades encontradas.
- Consultar a temperatura atual.
- Visualizar a sensação térmica, umidade e velocidade do vento.
- Consultar a previsão do tempo para os próximos 5 dias.
- Adicionar cidades aos favoritos.
- Visualizar e acessar as cidades favoritas.
- Salvar os favoritos no navegador utilizando localStorage.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- API Open-Meteo
- localStorage

## Objetivo
Projeto pessoal desenvolvido para praticar conhecimentos em desenvolvimento Front-end, integração com APIs e manipulação de dados utilizando JavaScript.
